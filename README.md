# Claudia Ibáñez · Portfolio de desarrollo web

Web profesional con la que presento mis servicios de diseño y desarrollo web para negocios.

🔗 **[claudiaibanez.com](https://claudiaibanez.com)**

## Qué incluye
- Portada con servicios, paquetes y proyecto destacado.
- Páginas de SEO local: diseño web en Pamplona, webs para peluquerías y tiendas online en Navarra.
- Blog con artículos para pequeños negocios.
- Páginas legales: aviso legal, privacidad, cookies y condiciones.

## Cómo está hecha
- HTML, CSS y JavaScript, sin frameworks.
- Rendimiento: imágenes WebP adaptadas a móvil y tipografías precargadas.
- Accesibilidad: contraste revisado.
- Seguridad: cabeceras HTTP configuradas en `_headers`.
- Estadísticas de visitas sin cookies.
- SEO: `sitemap.xml`, `robots.txt` y metadatos para Google.
- Desplegada en **Cloudflare Pages**, con publicación automática en cada `git push`.
