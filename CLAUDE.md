# Web de Claudia Ibáñez (claudiaibanez.com)

Web estática (HTML y CSS, sin compilación) alojada en Cloudflare Pages.

## Imágenes para Instagram

Cualquier imagen para Instagram (posts, carruseles, historias) se hace siguiendo `redes/GUIA.md` y con la plantilla de `redes/`, para que todo el feed tenga la misma imagen.
